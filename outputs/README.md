# Outputs Directory Structure

This directory contains all experiment outputs, including trained model checkpoints, evaluation results, and comparison analyses from the federated learning workflow.

## Directory Organization

### Trained Model Checkpoints

```
dscatnet_centralized_{dataset}/
├── checkpoints/
│   ├── best_model.pt          # Best performing checkpoint
│   └── latest_model.pt        # Latest checkpoint
├── config.json                # Training configuration & metadata
├── training_log.txt           # Training metrics over time
└── {other_files}/
```

```
dscatnet_federated_{dataset}_{strategy}/
├── checkpoints/
│   ├── best_model.pt
│   └── latest_model.pt
├── config.json                # Federated training config (clients, rounds, alpha)
├── training_log.txt
└── results.json               # Per-round aggregation metrics
```

**Example folders:**
- `dscatnet_centralized_ham10000/` — Centralized baseline on HAM10000
- `dscatnet_federated_ham10000_iid/` — Federated IID (α=10.0) on HAM10000
- `dscatnet_federated_all_datasets_non_iid/` — Federated Non-IID (α=0.5) on mixed domains

## Evaluation Results (Notebook 02)

Generated by: **notebooks/02_model_evaluation.ipynb**

```
evaluation_dscatnet_{experiment_name}/
└── {DATASET}/
    ├── results_latest.json              # Latest evaluation run (predictions + metrics)
    ├── results_YYYYMMDD_HHMMSS.json     # Timestamped evaluation archive
    ├── metrics_summary.csv              # Aggregated metrics: accuracy, F1, AUC, etc.
    ├── per_class_metrics.csv            # Per-class: Precision, Recall, F1 for each skin lesion type
    ├── confusion_matrix.csv             # Raw confusion matrix (rows=true, cols=predicted)
    ├── kpi_dashboard.png                # Summary visualization (3×2 KPI tiles)
    ├── confusion_matrix.png             # Heatmap with class labels
    ├── per_class_metrics.png            # Per-class Precision/Recall/F1 comparison
    ├── roc_curves.png                   # Multi-class ROC curves with AUC per class
    ├── confidence_analysis.png          # Prediction confidence distribution
    ├── bootstrap_samples.csv            # Bootstrap resampling results (1000 iterations)
    ├── bootstrap_summary.csv            # Bootstrap: mean, std, 95% CI per metric
    └── bootstrap_metric_ci.png          # Bootstrap confidence intervals plot
```

**Example:**
```
evaluation_dscatnet_centralized_ham10000/
└── HAM10000/
    ├── results_latest.json
    ├── metrics_summary.csv
    ├── per_class_metrics.csv
    └── *.png
```

**Notes:**
- Each evaluation generates a timestamped JSON (`results_YYYYMMDD_HHMMSS.json`)
- `results_latest.json` is a symlink/copy of the most recent run for easy access
- One folder per (experiment, dataset) pair
- If you evaluate the same checkpoint multiple times, results are **appended with timestamps**

## Comparison Analysis (Notebook 03)

Generated by: **notebooks/03_fl_vs_centralized_comparison.ipynb**

```
evaluation_comparison_dscatnet_{experiment_name}/
├── {DATASET}/
│   ├── {DATASET}_comparison.csv         # Model comparison (Centralized vs Federated)
│   ├── {DATASET}_comparison.json        # Same data as CSV, JSON format
│   ├── {DATASET}_head_to_head.csv       # Head-to-head table (includes Paper reference if available)
│   ├── comparison_bar_chart_{DATASET}.png    # Metrics bar chart (Accuracy, F1, Precision, Recall, AUC)
│   ├── comparison_radar_{DATASET}.png       # Multi-metric radar chart
│   └── confusion_matrix_comparison.png      # Optional: side-by-side confusion matrices
│
└── all_datasets/                        # Batch mode aggregation (when DATASET_SELECTION='all')
    ├── all_datasets_comparison.csv      # Aggregated comparison across all datasets
    ├── all_datasets_comparison.json
    ├── thesis_main_results_table.csv    # For thesis: curated metrics table
    ├── thesis_bootstrap_gap_table.csv   # Gap analysis vs baselines
    ├── thesis_communication_efficiency.csv  # Communication cost metrics
    └── thesis_communication_vs_accuracy.png # Communication trade-off visualization
```

**Example:**
```
evaluation_comparison_dscatnet_ham10000/
├── HAM10000/
│   ├── HAM10000_comparison.csv
│   ├── HAM10000_head_to_head.csv
│   ├── comparison_bar_chart_HAM10000.png
│   └── comparison_radar_HAM10000.png
│
└── all_datasets/
    ├── all_datasets_comparison.csv
    └── thesis_*.csv
```

**Notes:**
- Creates **one subdirectory per dataset** evaluated
- Compares all models (Centralized + Federated variants) on that dataset
- `all_datasets/` folder is created only if running in batch mode (evaluating multiple datasets)
- Thesis-specific exports are generated if DATASET_SELECTION='all'

## How to Reproduce

### 1. Train Models
```bash
python run_experiment.py  # Generates dscatnet_centralized_* and dscatnet_federated_* folders
```

### 2. Evaluate Individual Models (Notebook 02)
```
notebooks/02_model_evaluation.ipynb
├── Set: EVALUATION_EXPERIMENT = "dscatnet_centralized_ham10000"
├── Set: EVALUATION_DATASET_NAME = "HAM10000"
└── Run all cells → Creates: evaluation_dscatnet_centralized_ham10000/HAM10000/
```

### 3. Compare Models (Notebook 03)
```
notebooks/03_fl_vs_centralized_comparison.ipynb
├── Set: DATASET_SELECTION = "HAM10000"
├── Set: CENTRALIZED_EXPERIMENT = "dscatnet_centralized_ham10000"
├── Set: FEDERATED_EXPERIMENTS = ["dscatnet_federated_ham10000_iid", "dscatnet_federated_ham10000_non_iid"]
├── Run cells 1-12 → Creates: evaluation_comparison_dscatnet_ham10000/HAM10000/
├── Run cell 13 (Convergence) → Adds convergence_*.png and convergence_summary.csv
└── Batch mode: Set DATASET_SELECTION='all' to compare across all datasets
```

## File Naming Conventions

| Pattern | Meaning |
|---------|---------|
| `dscatnet_centralized_*` | Centralized training baseline |
| `dscatnet_federated_*_iid` | Federated learning with IID (α=10.0) |
| `dscatnet_federated_*_non_iid` | Federated learning with Non-IID (α=0.5) |
| `evaluation_dscatnet_*` | Single-model evaluation (Notebook 02) |
| `evaluation_comparison_dscatnet_*` | Multi-model comparison (Notebook 03) |
| `results_latest.json` | Most recent evaluation for quick access |
| `thesis_*.csv` | Outputs formatted for academic paper/thesis |

---

## Size Guidelines

- **Checkpoint files** (~350-500 MB per model)
- **Evaluation JSON** (~5-50 MB per evaluation, depends on dataset size)
- **CSV exports** (~100 KB per comparison)
- **PNG images** (~100-500 KB per visualization)

**Estimated total size for full workflow (3 datasets × 3 models):** ~5-10 GB
