# Outputs Directory Structure

This directory contains the complete artifact trail for the project: training runs, evaluation exports, multi-dataset comparisons, convergence plots, and research-ready summary tables.

## Top-Level Layout

The outputs are organized into three layers:

1. Training runs: `dscatnet_*`
2. Evaluation exports: `evaluation_dscatnet_*`
3. Comparison exports: `evaluation_comparison_dscatnet_*`

The comparison layer is the most useful one for the research results section, because it contains the per-dataset comparisons for ISIC2018, ISIC2019, ISIC2020, and PAD-UFES-20, plus the aggregated `all_datasets` summary.

---

## Training Runs

These folders contain the raw outputs from the training stage for each experiment:

```
dscatnet_centralized_{dataset}/
├── checkpoints/
│   ├── best_model.pt          # Best weights for inference
│   ├── best_checkpoint.pt     # Full state for resuming training
│   └── checkpoint_*.pt        # Periodic checkpoints
├── config.json                # Effective training configuration
├── results.json               # Final metrics, history, and environment info
└── experiment.log             # Training log
```

```
dscatnet_federated_{dataset}_{strategy}/
├── checkpoints/
│   ├── best_model.pt
│   ├── best_checkpoint.pt
│   └── checkpoint_*.pt
├── config.json                # Effective federated configuration
├── results.json               # Per-round metrics, history, and environment info
└── experiment.log             # Training log
```

### What `results.json` contains

The training `results.json` files store:

- Best validation metric and the epoch or round where it occurred
- Final validation metric
- Training history across epochs or rounds
- Total training time
- Test metrics when a separate test split exists
- Environment metadata such as Python, PyTorch, CUDA, GPU name, and GPU memory capacity

### Example training folders

- `dscatnet_centralized_ham10000/`
- `dscatnet_centralized_padufes20/`
- `dscatnet_centralized_all_datasets/`
- `dscatnet_federated_ham10000_iid/`
- `dscatnet_federated_ham10000_non_iid/`
- `dscatnet_federated_padufes20_iid/`
- `dscatnet_federated_padufes20_non_iid/`
- `dscatnet_federated_all_datasets_iid/`
- `dscatnet_federated_all_datasets_non_iid/`

### Important note on IID / non-IID naming

In this repository, the federated IID variants use a very high Dirichlet alpha to approximate uniform client distributions. The non-IID variants use a lower alpha to introduce stronger heterogeneity.

## Evaluation Exports

These folders are generated by `notebooks/02_model_evaluation.ipynb` and contain one subfolder per evaluated dataset.

```
evaluation_dscatnet_{experiment_name}/
└── {DATASET}/
    ├── results_latest.json
    ├── results_YYYYMMDD_HHMMSS.json
    ├── metrics_summary.csv
    ├── per_class_metrics.csv
    ├── confusion_matrix.csv
    ├── bootstrap_metric_samples.csv
    ├── bootstrap_metric_summary.csv
    ├── env_info.json
    ├── kpi_dashboard.png
    ├── confusion_matrix.png
    ├── per_class_metrics.png
    ├── roc_curves.png
    ├── confidence_analysis.png
    └── bootstrap_metric_ci.png
```

### What these files are for

- `results_latest.json`: the most recent evaluation snapshot, with metrics, per-sample predictions, confusion matrix, and confidence statistics.
- `results_YYYYMMDD_HHMMSS.json`: timestamped archive of each evaluation run.
- `metrics_summary.csv`: compact global metrics table.
- `per_class_metrics.csv`: per-class precision, recall, F1, and support.
- `confusion_matrix.csv`: raw confusion matrix for replotting or further analysis.
- `bootstrap_metric_samples.csv` and `bootstrap_metric_summary.csv`: bootstrap-based uncertainty estimates.
- `env_info.json`: environment metadata for reproducibility.
- PNG files: visual summaries of performance, calibration, and class-wise behavior.

### The evaluation visuals

The standard evaluation figures are:

- `kpi_dashboard.png`: at-a-glance performance dashboard
- `confusion_matrix.png`: confusion matrix heatmap
- `per_class_metrics.png`: class-wise precision/recall/F1 comparison
- `roc_curves.png`: multi-class one-vs-rest ROC curves
- `confidence_analysis.png`: prediction confidence distribution and correct vs incorrect separation
- `bootstrap_metric_ci.png`: confidence intervals for key metrics

### Datasets represented here

The evaluation folders appear for the same datasets used in the project:

- HAM10000
- ISIC2018
- ISIC2019
- ISIC2020
- PAD-UFES-20

## Comparison Exports

These folders are generated by `notebooks/03_fl_vs_centralized_comparison.ipynb` and compare centralized vs federated IID vs federated non-IID results.

```
evaluation_comparison_dscatnet_{experiment_name}/
├── {DATASET}/
│   ├── {DATASET}_comparison.csv
│   ├── {DATASET}_comparison.json
│   ├── {DATASET}_head_to_head.csv
│   ├── comparison_bar_chart_{DATASET}.png
│   ├── comparison_radar_{DATASET}.png
│   ├── {DATASET}_accuracy_bar.png
│   ├── confusion_matrix_{DATASET}.png
│   └── per_class_comparison_{DATASET}.png
│
├── all_datasets/
│   ├── all_datasets_comparison.csv
│   ├── all_datasets_comparison.json
│   ├── results_table.csv
│   ├── bootstrap_gap_table.csv
│   ├── communication_efficiency.csv
│   ├── comparison_artifacts_manifest.json
│   └── communication_vs_accuracy.png
│
└── convergence/
    ├── convergence_summary.csv
    ├── convergence_by_dataset_all_datasets.png
    ├── convergence_by_dataset_ham10000.png
    ├── convergence_by_dataset_padufes20.png
    └── federated_iid_vs_noniid.png
```

### What the comparison files are for

- `{DATASET}_comparison.csv` and `{DATASET}_comparison.json`: the main comparison tables for centralized, federated IID, and federated non-IID.
- `{DATASET}_head_to_head.csv`: compact comparison table, useful for summary tables.
- `comparison_bar_chart_{DATASET}.png`: side-by-side comparison of the main metrics.
- `comparison_radar_{DATASET}.png`: multi-metric profile of each approach.
- `{DATASET}_accuracy_bar.png`: accuracy-only summary.
- `confusion_matrix_{DATASET}.png`: confusion matrix comparison across methods.
- `per_class_comparison_{DATASET}.png`: per-class precision and recall comparisons.

### What the `all_datasets` folder adds

The `all_datasets` folder is the most relevant summary for the combined experiment. It contains:

- `all_datasets_comparison.csv` and `all_datasets_comparison.json`: aggregated multi-dataset comparison.
- `results_table.csv`: compact table with best validation, final validation, test accuracy where available, and training time.
- `bootstrap_gap_table.csv`: bootstrap confidence intervals for the performance gap.
- `communication_efficiency.csv`: communication-cost estimates for federated experiments.
- `communication_vs_accuracy.png`: communication trade-off visualization.
- `comparison_artifacts_manifest.json`: inventory of generated comparison artifacts.

### What the convergence files are for

The convergence folder is used to analyze training dynamics:

- `convergence_summary.csv`: round-by-round or epoch-by-epoch summary values.
- `convergence_by_dataset_*.png`: accuracy and loss curves per dataset.
- `federated_iid_vs_noniid.png`: direct comparison between IID and non-IID training behavior.

## How to Reproduce

### 1. Train models

```bash
python run_experiment.py
```

This generates the `dscatnet_centralized_*` and `dscatnet_federated_*` folders.

### 2. Evaluate models

Run `notebooks/02_model_evaluation.ipynb` with the experiment and dataset you want.

### 3. Compare models

Run `notebooks/03_fl_vs_centralized_comparison.ipynb` and select the datasets and experiments to compare. Use `DATASET_SELECTION='all'` to generate the multi-dataset comparison layer.

## File Naming Conventions

| Pattern | Meaning |
|---------|---------|
| `dscatnet_centralized_*` | Centralized training run |
| `dscatnet_federated_*_iid` | Federated run with near-IID client partitions |
| `dscatnet_federated_*_non_iid` | Federated run with non-IID client partitions |
| `evaluation_dscatnet_*` | Evaluation exports from Notebook 02 |
| `evaluation_comparison_dscatnet_*` | Comparison exports from Notebook 03 |
| `results_latest.json` | Most recent evaluation snapshot |
| `results_YYYYMMDD_HHMMSS.json` | Timestamped evaluation archive |
| `per_class_metrics.csv` | Per-class performance table |
| `confusion_matrix.csv` | Raw confusion matrix |
| `communication_efficiency.csv` | Communication-cost summary |

## Practical Size Expectations

- Checkpoints: large binary files, typically the heaviest artifacts.
- Evaluation JSON and CSV: light to medium size, easy to parse for analysis.
- PNG figures: compact visual summaries for reporting.
